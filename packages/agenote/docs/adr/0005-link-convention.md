# 记忆库 `[[路径]]` 链接约定与完整性检查

**Status**: accepted

记忆库条目（`memories/*.md`）之间用 Wiki 式 `[[路径]]` 做单源引用；
Org 经验卡片的关联仍用 `[[file:]]` / `[[id:]]`，不在此约定内。
`linkcheck` 只做只读检查（坏链 / 孤儿），不自动改写；修复由 agent
按报告手动执行（对齐 ADR-0004：CLI 只读发现 + 原子写命令）。

## Why

- Cognition 纪律要求记忆条目单源引用：一个事实只存一处，别处 `[[ ]]` 引用它。
- 无检查则引用腐烂无声：目标被移动/删除后，引用方无任何告警。
- 检查必须是只读的：坏链可能是“目标该建”也可能是“引用该删”，取舍需读正文，
  CLI 按天数/存在性自动改会误伤（同 ADR-0004 拒自动归档的理由）。

## 约定

- **相对记忆根**：`[[路径]]` 相对记忆根解析（人类域 `KB_ROOT/memories/`，
  agent 域为对应 `memories/` 子目录）；开头的 `/` 按相对处理，不许跳出记忆根。
- **`.md` 可省扩展名**：`[[foo]]` 即 `foo.md`；有扩展名则原样解析。
- **大小写与空格**：大小写敏感（POSIX 原样比对）；首尾空格忽略，内部空格保留。
- **别名与锚点**：`[[目标|别名]]` 取 `|` 前部分，`#锚点` 忽略。
- **不在此列**：`[[file:]]` / `[[http:]]` / `[[https:]]` / `[[id:]]` 等外部前缀
  直接排除（Org 双段式 `[[file:x][描述]]` 因内层括号本就匹配不上）。

## 定义

- **坏链**：引用目标不存在、不可读，或为 symlink（全仓 S8 口径拒 symlink）。
- **孤儿**：记忆根下存在、但无任何 `[[ ]]` 指向的 `.md` 条目文件；
  入口索引文件本身豁免（`check_links(exempt=("index.md",))`，入参可覆盖）。

## Considered Options

- **复用 Org `[[file:]]` 写记忆引用**：被拒。`file:` 是卡片文件关联语义，
  与记忆条目的逻辑引用混用后，review 的“关联数”与链接检查互相污染。
- **检查发现坏链自动删引用**：被拒。删引用是语义取舍（ADR-0004 铁律），
  CLI 只报告，agent 用原子命令显式修。
- **约定进 `config.py` SCHEMA**：被拒。只有一处用（linkcheck）→ 留代码注释；
  两处以上用才进 spec/。当前阈值零配置，硬编码于 `linkcheck.py`。

## Consequences

- `linkcheck.extract_links / resolve_link / check_links` 纯函数（无落盘、无锁）。
- `curator.cmd_review` 末尾追加“链接完整性”一节：有引用逐条展示 ✅/❌，
  零引用单行带过（不断现有 golden 快照的零引用输出形状，只增一行）。
- `dream` 侧零代码改动：dream 调用方由 agent 按本约定组合 `check_links`。
